# 5C07 — 霍格華茲魔咒決鬥

非官方學生遊戲。以使用者提供的完整 HTML 為基礎修正並整理為純前端 HTML、CSS、JavaScript，不需安裝套件，直接開啟 index.html 即可遊玩。沒有資料上傳、帳戶或伺服器儲存。

## 玩法

1 對 1 或 2 對 2（玩家與 AI 盟友對戰 AI 隊伍），先取得四勝獲勝。選咒、選目標，再確認。所有角色選完指令後結算：復原解除昏迷、防禦及繳械優先，其餘按角色順序執行。詳細效果列於遊戲按鈕及規則中。

本次以最新完整版本為準，沒有加入較早不完整版本的學院天賦及英式語音。

## 2026-11-02 UI／UX 重做

- 回合結算改為逐步播放：先「指令揭曉」，再按 復原 → 防禦 → 繳械 → 其他魔咒 一步一步顯示，每步有施法者、魔咒、目標及結果大字說明。
- 結算速度可選慢、標準、快、逐步（自己按「下一步」）；可點決鬥場中央或按空白鍵看下一步，亦可「略過動畫」。設定存於瀏覽器。
- 傷害／回復數字浮現、受擊震動、施法光束、屏障／護法／昏迷／索命咒冷卻徽章，HP 條按當步數值變化。
- 指令區改為三步驟（選魔咒 → 選目標 → 確認），右側說明卡顯示完整效果、目標按鈕及「你將對誰施展甚麼」；亦可直接點角色卡選目標。
- 每局結束改為結果視窗，由玩家按「開始下一局」才繼續；四勝後顯示冠軍視窗。
- 頂部比分改為四格勝場指示；新增規則視窗（流程及 12 個魔咒一覽）；開啟選單或規則時暫停結算。
- 對戰紀錄按回合分段。手機版角色卡兩欄並排、說明卡貼底。
- 遊戲規則及數值沒有改動。

## 早前修正

- 清除轉貼用跳脫符號及圖片佔位文字；圖片只收到文字描述，暫以 emoji 取代，沒有保留原像素圖。
- 補齊 Imperio、Sectumsempra、Protego、Patronum、Riddikulus、Expelliarmus、Rennervate 的有效結算；原本 Riddikulus 只在被攻擊時讀取指令，現在須有效施法才有防禦效果。
- 索命咒獲勝立即終止整個結算，避免 forEach return 無法中斷導致重複計分。
- 使用明確的選擇／等待／結算／局間／選單狀態，防止連按、倒下者施法、無效目標及舊 AI 計時器跨模式執行。
- 每回合清空舊指令及選擇；索命咒使用後等待完整五回合，每局重新冷卻。
- 昏迷跳過下一次行動，隊友復原優先處理；自我昏迷不能自救。
- 保留首次模式選單，移除直接自動開始；四勝後顯示結果與重開選項。
- 音訊延後至互動建立，缺少支援仍可遊戲；音效失敗不會中斷對戰。
- 手機角色卡改為每隊直排、鍵盤焦點及對話框焦點循環、減少動態效果偏好。
