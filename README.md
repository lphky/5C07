# 5C07 — 魔咒決鬥

非官方學生純前端遊戲，沒有帳戶、資料上傳或後端。

2026-11-05 依使用者提供的最新 HTML 更新：單人對電腦、八個魔咒、率先四勝。此附件取代舊版 1v1／2v2、12 魔咒規則。保留附件的語音、深色金邊外觀及數值；索命咒減少對手目前 HP 的一半（傷害向下取整，不能致命），護盾反彈下一次攻擊且不疊加。AI 保留附件的六種隨機選招。

## 操作

點魔咒按鈕出招，閱讀結果，再按「繼續：電腦出招」。電腦結果會保留到玩家下一次出招；「本局紀錄」可展開重讀。局間須按「開始下一局」，四勝後保留最終比分，按「重新開始」再玩。

## 修正

- 移除自動 AI 計時器，重開不會殘留舊回合；防止連按及無效魔咒。
- 索命咒施放後須完成另外三次玩家行動才可再次施放。
- 勝負只計一次，四勝不會立即清除結果。
- 浮動數字改為視窗定位，修正捲動後偏移；治療顯示實際回復量。
- 鍵盤可使用原生按鈕，等待及冷卻時真正停用；移除禁止縮放，手機頂欄可換行。
- 顯示護盾狀態、完整結果與紀錄；語音失敗不會中斷遊戲。

## 檔案及驗證

直接開啟 index.html。外觀依賴 Tailwind CDN、Font Awesome 及 Google Fonts，需網絡；語音依瀏覽器支援。

執行 `node --check game.js`、`node test.cjs`。測試紀錄見 TEST-RESULTS.md。
